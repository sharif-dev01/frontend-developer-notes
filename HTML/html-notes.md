
# HTML Notes

## 1. What is HTML?

HTML stands for HyperText Markup Language.
It defines the structure of a web page.

## 2. Basic HTML Structure

    <!DOCTYPE html>
    <html lang="en">
    <head>
        <meta charset="UTF-8">
        <title>My Website</title>
    </head>
    <body>
        <h1>Hello World</h1>
        <p>My first webpage.</p>
    </body>
    </html>

## 3. Important Tags

- h1: Main heading
- p: Paragraph
- a: Link
- img: Image
- div: Container
